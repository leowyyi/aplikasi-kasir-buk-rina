APLIKASI KASIR
==============

1. Ekstrak folder ZIP ke C:\xampp\htdocs\
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka http://localhost/phpmyadmin
4. Pilih Import, lalu masukkan file aplikasi_kasir.sql.
   File SQL membuat database bernama aplikasi_kasir.
5. Buka: http://localhost/aplikasi_kasir/kasir/

Tidak ada halaman login admin.
Menu: Kasir, Produk, Riwayat transaksi, dan cetak struk.
Teknologi: HTML, CSS, PHP (PDO), MySQL.
